# dcx-hackathon
Title: GDS Journey Builder
One-line pitch:
Turn a plain-English description of a government service into a page-by-page journey that teams can preview, inspect as JSON and React code, and use as a starting point for development.
How we used AI:
We used Vercel v0 to build and iterate on the interface. The application uses generative AI at runtime to turn a service description into a structured journey. Users can review the generated pages, JSON and code.

Live URL : https://alpha-taupe-rho.vercel.app/
